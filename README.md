# Task Board — Desk & Bench
A standalone task board with sections, due dates, daily focus and overdue task lists.
English and Turkish are available from the menu.

- Use online: https://ugurlab.github.io/task-board/
- Download: save index.html and open it in your browser.
- Catalogue: https://ugurlab.github.io/desk-and-bench/
- Feedback: https://github.com/ugurlab/task-board/issues

## Data and backups
No account or cloud connection. Tasks stay in the current browser.
Export JSON backups regularly. Clearing browser data can erase tasks.
The downloaded HTML runs offline. Local file storage behavior can vary between browsers.
The online version retains the same storage key as the original catalogue-hosted version.

## Türkçe
Bölmeler, son tarihler, günlük odak ve geciken görev listesi içeren Görev Panosu.
İndirmek için index.html dosyasını kaydedip tarayıcıda açın.
Dil seçimi menüdedir. Görevler bu tarayıcıda saklanır; eşitleme yoktur.
Menüden düzenli JSON yedeği indirin.
